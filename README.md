# Drive Backup Connector

Static public information and privacy policy for a private-use Google Drive backup connector. This repository contains no credentials or backup data.

The site is plain HTML with no build step, scripts, forms or analytics.

Run the checks with `python3 -m unittest discover -s tests -v`. Serve the repository with `python3 -m http.server 8765 --bind 127.0.0.1` for a local preview.
